# Project Control Studio

Public documentation and support for Project Control Studio, a VS Code extension by Raresteak.

## Release status

The first Marketplace preview is being prepared. No public extension package is hosted in this repository yet. Source code is private.

## Current capabilities

- Personal workspace tasks with statuses, assignees, due dates, milestones and dependencies.
- Optional shared GitHub Issues across selected repositories.
- Read-only local Git inspection and optional Codex completion/code reviews.
- Optional previewed Microsoft Teams progress snapshots.

Coding-agent task execution is not included. Local personal tasks require no GitHub, Teams or Codex account. Optional services require their own accounts/tools and may have usage costs.

## Support

Use this repository's Issues page for bugs and questions. Include extension version, VS Code version, operating system and minimal reproduction steps. Do not include passwords, tokens, Teams webhook URLs, private repository contents, personal task data or sensitive logs. Redact screenshots and error text before posting.
